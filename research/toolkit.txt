Scope
Version 0.1.0 is an installable source package named constructive-access.
The JSON workflow accepts exactly two finite normalized classical rational
instruments. Inputs explicitly state target labels, interventions, preparation,
resource meanings, action costs, excluded resource items and sampling target.
Quantum/general linear models remain an advanced Python interface requiring
separate physical admissibility evidence. No empirical data are generated.

Public APIs
  load_contract(path_or_mapping_or_contract) -> immutable Contract
  analyze(contract_or_mapping_or_path) -> JSON-compatible report
  verify_report(contract_or_mapping_or_path, report) -> verification result
  CLI: constructive-access analyze CONTRACT -o REPORT
       constructive-access verify CONTRACT REPORT

The checker receives an independently chosen contract, reconstructs the paired
model, validates filtered closure expansions without synthesis or rank, and
recomputes the reported complete experiment and statistical quantities. It
does not infer calibration. Reports omit unchecked search diagnostics.

  complete laws (3/4,1/4) versus (1/4,3/4); TV1/2; one-record Bayes risk1/4;

  conditional each-hypothesis error9/100 plus failure1/100; batch charge84.

grammar.json: only a drive followed by a read is a complete accepted protocol.

Sampling and calibration assumptions
Conditional on pre-acquisition calibration information, every fixed actual
hypothesis generates iid classification records. A simultaneous calibration
event certifies those conditional whole-record laws. Classification records
are not reused to choose/calibrate the event or threshold. The software
checks rational consequences of stated bounds, not their empirical validity.
The selected robust event is {transcripts: P0>P1}. Its nominal contrast is TV.
A positive event gap yields a Hoeffding count from an outward rational log
enclosure. It is a sufficient count, not statistical or energy optimality.

Limits
No API certifies a new physical law, four engineering grand challenges,
historical priority, external peer review, total unobserved energy, quantum
scalability, arbitrary neural-network latent state, or model completeness.
The least nonzero-witness action charge is not the least total repeated
experimental charge. The user-specified transcript cap may stop statistical
evaluation without changing the separate exact access result. Community
validation and physical calibration remain distinct evidence requirements.
