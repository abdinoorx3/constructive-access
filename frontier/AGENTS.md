# Realization frontier research

Abdinoor / 2D Labs. Inherit ../AGENTS.md. Preserve all prior releases.

Goal: find and prove a useful extension beyond the three-state occupation witness,
with a quantitative finite-data or physical-resource consequence. Investigate
larger classical realization requirements, operational limits of restricted
records, and robust alternatives to exact spectral inference. Follow evidence;
do not declare historical novelty, empirical confirmation or a breakthrough by
fiat. Full environment access does not establish scientific truth.

Root owns integration, shared goals, logs and release. Each agent owns only its
assigned named files in research/, code/, tests/, results/ and manuscript/.
No external messages, submissions, purchases or laboratory operations are part
of this local research task. Read-only public literature/data access is allowed.
The loop is candidate -> closest prior art -> exact small case -> adversarial
counterexample -> proof -> independently checked executable certificate ->
matched comparison -> promotion, correction or rejection.

Distinguish exact continuum data, finite samples, bounded observation windows,
unknown preparation/readout, common homogeneous dynamics, control memory and
physical energy. A realization-size bound is not automatically a thermodynamic
cost or a claim that every classical explanation is impossible.
