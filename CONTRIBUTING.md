# Contributing to Constructive Access

Corrections, counterexamples, independent derivations and reproduction reports
are welcome. Use the repository issue tracker once hosted, or contact
[helloworld@2dai.org](mailto:helloworld@2dai.org).

For a scientific issue, identify the theorem or claim ID, the assumptions being
used, and a reproducible calculation or precise objection. For a software issue,
include the release version, command, Python and dependency versions, observed
output, and the smallest relevant input. Do not include confidential data.

The work distinguishes proofs, simulations and physical measurements. A proposed
change should preserve that distinction and report any new assumptions, failure
cases or resource costs. Changes to frozen experiments require a new version;
existing records should remain available.

Discuss substantial contributions before preparing a pull request. Copyright
and licensing permission must be agreed before contributions are merged,
including permission needed for the project's commercial licensing model.
Submitting an issue does not transfer your copyright. Existing third-party
materials retain their original licenses and attribution requirements.
