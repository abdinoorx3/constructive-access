# Virtual laboratory goal and assignments

Goal: convert model certificates into experimentally credible protocols by
simulating trajectories, apparatus and data analysis, and proving corrections
for failures uncovered. The integrated endpoint is an improved cumulative
reference and runnable virtual-laboratory suite, not a claim of measured physics.

Loop: specify -> freeze design/seed -> generate independent physical records ->
analyze blind to hidden truth -> compare calibration/coverage/power/cost ->
challenge -> improve theory/design -> hold-out evaluation -> release.

Assignments:
- thermodynamic_bridge: thermodynamic trajectory and detector laboratory.
- access_hierarchy: qubit/classical dimension-witness laboratory and robustness.
- spectral_frontier: timing/exposure closure theory, exact checks and limits.
- realization_limits: dependent-record inference and laboratory sampling design.
- frontier_literature: prior art and experiment feasibility/assumption audit.
- frontier_redteam: independent adversarial review and simulation validation.
- root: integration, matched design improvements, shared evidence and release.
